# Security

## Reporting a vulnerability

Report suspected vulnerabilities privately through GitHub's private vulnerability reporting for this repository:

[Report a vulnerability](https://github.com/Basantbhat162/offline-image-converter/security/advisories/new)

Do not disclose vulnerability details in a public issue, pull request, discussion, or other public channel. Include the affected file or feature, the steps needed to reproduce the issue, and any suggested mitigation you can safely provide.
